## 🌟 Project Overview

This project is a **Student Management System** implemented in C using a **Singly Linked List (SLL)**.

It allows efficient management of student records with dynamic memory allocation instead of fixed-size arrays.

💡 Each student record is stored as a node containing data and a pointer to the next node, forming a linked structure. 

---

## 🎯 Objective

- Manage student data dynamically  
- Implement core data structure concepts  
- Perform CRUD operations efficiently  

---

## 🧠 Problem Statement

Traditional systems using arrays:
- ❌ Fixed size  
- ❌ Inefficient insert/delete operations  

✅ This project uses **Linked List**, which allows:
- Dynamic memory allocation  
- Efficient insertion and deletion

## 📊 Data Structure Used

### 🔗 Singly Linked List

- Each node contains:
  - Student data  
  - Pointer to next node  

- Dynamic size (no fixed limit)  
- Efficient insertion & deletion
